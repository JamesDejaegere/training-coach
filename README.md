# Training Coach

Personal workout application: running, cycling, strength and mobility in one place, grounded in
Strava and Polar data. Built with .NET 10, Blazor (Interactive Server), .NET Aspire and SQLite.

- [Specification](docs/SPEC.md)
- [Decision log](docs/DECISIONS.md)

## Status

Design agreed (2026-10-17). Phase 1 (foundation) not started yet.

## Local data

Application data lives in `data/` (git-ignored). Secrets are stored with .NET User Secrets.
